Положите фото в папку нужной капсулы и запустите PUBLISH_OFF_CATALOG.
Список фото обновляется автоматически. Кнопка публикует сайт; Telegram не отправляет.

Для связи с SOLD OUT имя фото должно содержать код и цвет модели:
DO00663101_BEIGE.jpg или DO00663101_BEIGE_1.jpg.
Можно несколько фото одной модели: _1, _2 и далее.
Нельзя использовать только 1.jpg или IMG_1234.jpg: по ним невозможно определить товар.

SOLD OUT удаляет фото закончившихся моделей из всех папок капсул с резервной копией.
Повторная публикация не возвращает заблокированные модели.
